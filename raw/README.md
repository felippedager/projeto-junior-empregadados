# Dados brutos

Estes seis arquivos CSV vêm do dataset **E-commerce Data**, obtido no Kaggle:
<https://www.kaggle.com/datasets/lamskdna/e-commerce-data>

Não foram alterados neste repositório. A ingestão (`pipeline/ingestao.py`) só lê os arquivos
`.csv` e ignora este arquivo.
